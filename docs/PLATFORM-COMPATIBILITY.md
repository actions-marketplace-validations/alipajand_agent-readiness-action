# Platform compatibility

Evidence-based status of each integration on each platform, as of 2026-10-12. "Verified" means it
was run and observed; everything else says what is missing.

## Runtimes

| Runtime                     | Skill script / CLI                      | MCP server                                                            | Evidence                                                                                                                           |
| --------------------------- | --------------------------------------- | --------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| Node.js 24.11 (macOS arm64) | Verified                                | Verified                                                              | Full integrations suite (all tests pass)                                                                                           |
| Node.js 22.13 (macOS arm64) | Verified                                | Verified                                                              | MCP, worker, parity, and adversarial suites (56 tests) run locally on 22.13.0; CI runs the whole suite on 22.13.0                  |
| Node.js 22.12, 23.0 to 23.4 | Expected to work (no sandbox is needed) | Refused at startup: no stable permission model for the worker sandbox | `tests/mcp.spec.ts` starts the server reporting 22.12.0 and 23.4.0                                                                 |
| Node.js < 22.12             | Refused with a clear message            | Refused with a clear message                                          | `tests/nodeVersion.spec.ts`                                                                                                        |
| Linux (ubuntu-latest)       | Verified in CI                          | Verified in CI                                                        | The `integrations` job runs the whole suite on Node.js 22.13.0 and 24; see the pull request checks for the commit                  |
| Windows                     | Unverified                              | Unverified                                                            | Not tested. The permission flags, `realpath`, and the `SystemRoot`/`TEMP` passthrough were written for Windows but never run there |
