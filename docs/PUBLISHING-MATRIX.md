  clean install gives 0.1.2.

  `io.github.alipajand/agent-readiness` 0.1.1 and 0.1.2, with 0.1.2 latest ([entry](https://registry.modelcontextprotocol.io/v0/servers?search=io.github.alipajand/agent-readiness)). The
  Anthropic's plugin directory has the plugin submitted (2026-10-13, scanning; not approved or
  listed). Glama has the MCP server submitted (2026-10-13, awaiting review; not listed). Both
  submissions to mcpserver.dev failed with HTTP 500, yet a public mcpserver.dev page for the server
  was found on 2026-10-14; which process created it is unknown. MCPRush indexed the npm package on
  its own (notified by email 2026-10-14; never submitted to and not claimed). The Cursor Marketplace
  has not been submitted to.
