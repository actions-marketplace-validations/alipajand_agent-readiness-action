# Publishing matrix

Checked on 2026-10-12, after the GitHub release of the integrations
([`integrations-v0.1.1`](https://github.com/alipajand/agent-readiness-action/releases/tag/integrations-v0.1.1)). Status values: **PUBLISHED** (live), **READY** (all technical
work done and verified; only owner steps remain), **NEEDS WORK** (technical work or a verification
step is missing), **BLOCKED** (an external requirement prevents it), **SUBMITTED** (awaiting
review), **NOT TESTED** (the client was not available to test).

Two kinds of publication are tracked separately:

- **Published from this GitHub repository:** the action release v1.2.0, and the integrations
  release `integrations-v0.1.1`, from which the Agent Skill and the Claude Code plugin install
  directly (`npx skills add`, `claude plugin marketplace add`).
- **Official registries and directories:** npm has `@alipajand/agent-readiness-mcp` 0.1.1
  ([npm](https://www.npmjs.com/package/@alipajand/agent-readiness-mcp)). The MCP Registry, the Cursor Marketplace, and Anthropic's plugin directory have
  not been published to or submitted yet.

The Claude Code and MCP host checks in [RELEASE-CHECKLIST.md](RELEASE-CHECKLIST.md) § 3 passed in
signed-in sessions, so npm, the MCP Registry, and Anthropic's directory are not blocked by Cursor.
Only the Cursor Marketplace row waits on a Cursor test, which has not been run.
